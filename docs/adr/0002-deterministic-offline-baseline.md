# ADR 0002: Make the default path deterministic and offline

Status: accepted

The CI reference suite replays synthetic candidate responses and uses explainable deterministic metrics. Reviewers need no model account, API key, network access, or spend. This improves reproducibility and prevents provider instability from obscuring harness defects. The trade-off is limited semantic understanding; calibrated semantic evaluators are additive production extensions, not replacements for deterministic controls.
