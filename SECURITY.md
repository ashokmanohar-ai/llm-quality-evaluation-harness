# Security policy

Please report suspected vulnerabilities privately through GitHub's security advisory feature. Do not open a public issue containing secrets, private datasets, model credentials, exploitable prompts, or personal data.

The reference implementation stores only synthetic evaluation evidence. Real deployments must add organization-approved authentication, authorization, encryption, retention, monitoring, and a managed secret store before handling confidential data. See `docs/THREAT_MODEL.md` and `docs/GOVERNANCE.md`.
